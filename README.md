# Elevate-Labs-Internship-Task-2
Internship-Task-2

The Student Record Management System is a Java-based console application that helps in managing student data efficiently. It is designed using Object-Oriented Programming (OOP) concepts and provides a menu-driven interface for performing CRUD (Create, Read, Update, Delete) operations on student records.

The system uses an ArrayList to store and manage student information such as:
ID → Unique identifier for each student.
Name → Student’s full name.
Marks → Student’s marks/grades.

Through the CLI menu, users can:
➕ Add new student records.
📋 View all existing records.
✏️ Update student details using their ID.
❌ Delete a student record by ID.
This program is lightweight, beginner-friendly, and demonstrates core Java concepts such as classes, objects, collections, and exception handling.
